# Vendored fonts

IBM Plex Sans (Regular, SemiBold) and IBM Plex Mono (Regular), Latin1 subset,
woff2 only — exactly the three weights `src/styles.css` references.

These files are IBM's own pre-built subsets, taken unmodified from the
`@ibm/plex-sans` and `@ibm/plex-mono` npm packages. They are not re-subset here:
the SIL Open Font License reserves the name "Plex" for unmodified versions
(clause 3), so shipping IBM's own build avoids creating a Modified Version that
would not be allowed to carry the name.
